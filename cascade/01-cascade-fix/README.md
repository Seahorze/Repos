# Cascade-Odin-Project

01 - Cascade Fix
What this exercise is about
This exercise is about understanding how CSS decides which rule wins when two rules conflict. This is called the cascade.
The HTML and CSS file is already written. The goal is to fix the CSS without changing the HTML or the actual style values.

The three things that decide which CSS rule wins

Specificity - Some selectors are stronger than others

ID #id is the strongest
Class .class is in the middle
Type div, p is the weakest


Rule order - If two rules have the same strength, the one that comes last wins
Inheritance - Some properties like color are passed down from parent to child elements
