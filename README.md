# The Odin Project - My Journey

This repository holds all the exercises and projects I complete as I work through [The Odin Project](https://www.theodinproject.com/) curriculum.

## About The Odin Project

The Odin Project is a free, open source full stack web development curriculum. It covers everything from the basics of HTML and CSS to JavaScript, databases, and beyond. The curriculum is built and maintained by an open source community.

## What This Repo Contains

As I progress through the curriculum, this repository will grow to include exercises and projects covering:

- HTML foundations
- CSS foundations
- JavaScript
- And more as I progress...

Each folder in this repo represents a topic or exercise from the curriculum.
