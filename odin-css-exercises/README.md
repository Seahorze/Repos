# Odin Project - Intro to CSS Exercises

Practice exercises from The Odin Project foundations course.

## Exercises

### 01 - CSS Methods
Practiced the three ways to add CSS: external, internal, and inline.

### 02 - Class and ID Selectors
Learned when to use classes (reusable) vs IDs (unique elements).

### 03 - Grouping Selectors
Used commas to group selectors that share the same styles.

### 04 - Chaining Selectors
Targeted elements that have two specific classes at the same time.
